# Roadmap

Open Pet Office is an early Windows preview. Work proceeds from a recoverable collaboration core to project management, desktop reliability, and then ecosystem expansion.

## Completed

### v0.11 — Supervisor agent

- Persistent Missions and dependency graphs
- Dependency waves, stage reviews, and failure reassignment
- Isolated worker worktrees and snapshots
- Structured agent messages and supervisor final review
- Accurate completion, partial success, failure, cancellation, and interruption states

### v0.12 — Projects and sessions

- Create, continue, and reset context
- Rename, archive, restore, remove, and clean project attachments
- Project task filtering and pinned live cards
- Model capability labels and agent recommendations

### v0.13 — Desktop experience

- Multiple displays and fullscreen avoidance
- Quiet, standard, and detailed notification modes
- Typography, attachment, keyboard, and accessibility improvements
- Local crash reports, update checks, and optional code signing

## Next

- Unify single-agent and Mission execution around the App Server task model
- Project-level shared-memory retrieval and visualization
- Richer agent-message, dependency, and review views
- More provider quota adapters and budget policies
- Trusted automated builds, Windows signing, and an installer
- Evaluate macOS and Linux after Windows is stable

Priorities may change with real-world feedback. Use a [Feature request](https://github.com/Gu-kai-lei/Open-Pet-Office/issues/new?template=feature_request.yml) to describe the concrete workflow you need.
